# مجلد الصور - زيتونة بوك

هذا المجلد يحتوي على صور أغلفة الكتب والصور المرتبطة بالموقع.

## هيكل المجلد

\`\`\`
public/images/
├── covers/        # أغلفة الكتب
├── thumbnails/    # صور مصغرة
├── previews/      # صور المعاينة
├── authors/       # صور المؤلفين
└── categories/    # صور التصنيفات
\`\`\`

## إضافة صور جديدة

### 1. أغلفة الكتب
- ضع صور الأغلفة في مجلد `covers/`
- استخدم أسماء ملفات واضحة مثل: `الخيميائي.jpg`
- الأبعاد المفضلة: 400x600 بكسل (نسبة 2:3)
- الأحجام المقترحة: 50-200 كيلوبايت

### 2. الصور المصغرة
- ضع الصور المصغرة في مجلد `thumbnails/`
- الأبعاد: 200x300 بكسل
- الأحجام: 20-50 كيلوبايت

### 3. أنواع الملفات المدعومة
- JPG/JPEG (مفضل للصور الفوتوغرافية)
- PNG (مفضل للصور مع خلفية شفافة)
- WebP (أفضل ضغط وجودة)
- GIF (للصور المتحركة)

## إرشادات الجودة

### الأبعاد
- **أغلفة الكتب**: 400x600 بكسل (نسبة 2:3)
- **صور مصغرة**: 200x300 بكسل
- **صور المعاينة**: 800x1200 بكسل

### الجودة
- استخدم جودة 80-90% للـ JPG
- تأكد من وضوح النص على الغلاف
- تجنب الصور المشوشة أو منخفضة الدقة

### التسمية
- استخدم أسماء واضحة ومفهومة
- تجنب المسافات (استخدم _ أو -)
- استخدم الأحرف العربية أو الإنجليزية
- مثال: `كتاب_التوحيد.jpg` أو `quran_tafseer.png`

## أمثلة على الاستخدام

### في الكود
\`\`\`typescript
// إضافة صورة غلاف
imageManager.addImage(bookId, "/images/covers/الخيميائي.jpg", "cover")

// إضافة صورة مصغرة
imageManager.addImage(bookId, "/images/thumbnails/الخيميائي_thumb.jpg", "thumbnail")
\`\`\`

### في HTML
\`\`\`html
<img src="/images/covers/الخيميائي.jpg" alt="غلاف كتاب الخيميائي" />
\`\`\`

## نصائح للأداء

1. **ضغط الصور**: استخدم أدوات ضغط الصور لتقليل الحجم
2. **تنسيق WebP**: يوفر أفضل ضغط مع الحفاظ على الجودة
3. **الصور التدريجية**: استخدم JPEG التدريجي للتحميل السريع
4. **CDN**: فكر في استخدام CDN لتسريع تحميل الصور

## حقوق الطبع والنشر

- تأكد من أن لديك الحقوق القانونية لاستخدام الصور
- استخدم صور مجانية أو مرخصة
- اذكر المصدر إذا كان مطلوباً
